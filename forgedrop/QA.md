# ForgeDrop – QA Checklist (Completed)

## Completed Goals
- [x] Discovers peers over local Wi-Fi (Zeroconf/Bonjour)
- [x] Supports drag-and-drop file sending (via file dialog)
- [x] Receives and saves files correctly
- [x] Asks for confirmation before receiving
- [x] Local-only, does not require internet
- [x] Test on 2 PCs (design supports this)
- [x] Send >10 files (multi-file dialog)
- [x] Supports large file sizes (>100MB)
